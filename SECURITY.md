# Security policy

TorChat is privacy and security software. Do not report vulnerabilities in public issues.

Until a security contact is published, keep reports private and include:

- affected component and version;
- reproducible steps or a minimal proof of concept;
- security impact;
- whether message plaintext, private keys or metadata are exposed.

Do not include real private keys, personal messages or production onion-service credentials in a report.

No release may be described as cryptographically audited until an independent review has been completed and its scope is documented.
